# Foundation results

Reserved for reviewed outputs of `experiments/foundations/`. Each experiment
receives a matching directory with a provenance `manifest.json` and,
when appropriate, versioned figures, tables, and metrics.  Caches and temporary
logs do not belong here.

The implemented B1/B2/B12 directories contain `metrics.json` plus a uniform
`manifest.json`. Metrics record scientific outcomes; manifests record exact
configuration, code hashes, citekeys, command, Git state, and result hash.
