# G0 — General synthetic HLS instrument

G0 is the current policy-neutral generative framework for controlled HLS
worlds. It is infrastructure, not a theory and not evidence that HLS has
positive value.

## Contract

An environment is a composition

```text
E(Theta_Q, Theta_C, Theta_O, Theta_D, Theta_R, Theta_K, Theta_I)
```

where the blocks represent task demand, competence state, opportunity
generation, competence development, operational reward, resources/costs, and
information/coordination. `WORLD != POLICY`: the world never branches on
whether HLS, strong SEP, or SEP-Omega is evaluating it.

The common execution objects are `WorldState`, `Trajectory`, policy-facing
interfaces, and `SyntheticEnvironment`. Components are replaceable only when
the resulting composition remains mathematically valid.

## Current capability surface

- **Theta_Q:** replaceable task processes, including deterministic, indexed,
  stationary, and Markov forms used by the current gates.
- **Theta_C:** immutable competence states supporting arbitrary learner/task
  dimensions; A1 reference cases use `M=K=2`.
- **Theta_O:** opportunity kernels. A1 uses the mixture family
  `g_ik(rho)=(1-rho) ebar_k + rho e_ik`.
- **Theta_D:** explicit null and development actions, saturating competence
  transitions, finite-resource composition where declared, and signed
  transfer/interference kernels where declared.
- **Theta_R:** reward is separate from development; A1 uses competence-derived
  operational reward.
- **Theta_K:** explicit costs, budgets, capacities, and admissibility where a
  capability requires them.
- **Theta_I:** explicit policy information/coordination contracts. Full
  information is used by current A1/C1--C5 reference gates.

G0 hosts the current C1--C5 reference-gate capabilities: repeated endogenous
competence evolution, portfolio geometry, scarce development resources,
competence interactions, and dynamic task demand. C6--C8 are not implemented.

## Relation to RQ0

G0 enables exact and controlled tests of routing, opportunity, development,
and future competence. It must generate positive, null, boundary, adverse, and
reducible worlds. It must not encode an HLS bonus or a SEP penalty.
