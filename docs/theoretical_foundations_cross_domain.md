# Cross-domain foundations used by HLS

This is a compact import register, not a literature warehouse or a novelty
claim. External theory is used only when it addresses a declared HLS object
and can be mapped through [the ontology](hls_ontology.md).

## Current foundations

- **Organization/use of competences.** Garicano's organization-of-knowledge
  mechanisms provide a scoped foundation for routing, escalation, distributed
  knowledge, and task allocation. They do not define HLS or establish RQ0.
- **Development/evolution of competences.** Gutjahr-style competence dynamics
  provide a scoped foundation for learning-by-doing and dynamic allocation.
  The repository's B2 reproductions preserve the tested assumptions and
  failures; they do not establish an HLS result.
- **Learning, coordination, and dynamic capabilities.** The literature layer
  supplies bounded mappings for learning, distributed knowledge, capability
  change, and portfolio organization. These mappings remain supporting
  material, not additional HLS beams.

## Import discipline

For every future import, record: the source result and assumptions, the HLS
object it maps to, the mapping class, compatible units, what cannot be
inferred, and whether reproduction is necessary. Similar vocabulary is not
semantic equivalence. A result enters active HLS theory only when its current
scientific use is explicit.
