# Operational-development opportunity value

**Status:** DERIVED-IN-MODEL (2026-09-19). This note formalizes exact
analytical identities for stated reduced models. It neither establishes novelty
nor general superiority of joint or central management.

## 1. Purpose and semantic discipline

Operational allocation and competence development are distinct decisions:
\(a\) determines who executes current work, while \(d\) determines whether and
how an opportunity created by that work is used to modify competence. Routing
to an operational action can create a development opportunity; it does not by
itself imply training, transfer, or competence change.

This distinction instantiates the ontology maps

\[
a\longrightarrow W,\qquad (S,q,a,d,W)\longrightarrow E,\qquad
(S,E)\longrightarrow S'.
\]

Thus \(d\neq E^{ind}\neq\Delta S\). The reduced models below use
continuation value to value competence only through future operational value.

## 2. General operational-development decomposition

Let \(S\) be a competence state, \(q\) a current task, and

\[
a\in\mathcal A(S,q)
\]

an operational action. It produces immediate operational reward
\(R(S,q,a)\) and enables a feasible set of development actions

\[
d\in\mathcal D(S,q,a).
\]

Every opportunity set contains \(d=0\), interpreted as no use of the
opportunity, with

\[
C(S,q,a,0)=0,\qquad
P(S'=S\mid S,q,a,0)=1. \tag{A1}
\]

For \(d\), let \(C(S,q,a,d)\) be a cost expressed in the same value units as
the objective and let

\[
S'\sim P(\mathord\cdot\mid S,q,a,d).
\]

Let \(V(S)\) be continuation value before the next task and
\(\beta\in[0,1]\). Define

\[
\begin{aligned}
Q(S,q,a)
={}&R(S,q,a)\\
&+\max_{d\in\mathcal D(S,q,a)}
\left\{-C(S,q,a,d)+\beta\mathbb E[V(S')\mid S,q,a,d]\right\},
\end{aligned}
\]

and the development-opportunity value

\[
\Omega(S,q,a)=
\max_{d\in\mathcal D(S,q,a)}
\left\{-C(S,q,a,d)+\beta\left(
\mathbb E[V(S')\mid S,q,a,d]-V(S)\right)\right\}.
\]

### Proposition 1 — Opportunity-value decomposition

Under the preceding definitions,

\[
\boxed{Q(S,q,a)=R(S,q,a)+\beta V(S)+\Omega(S,q,a).}
\]

Consequently,

\[
a^*(S,q)\in\arg\max_{a\in\mathcal A(S,q)}
\{R(S,q,a)+\Omega(S,q,a)\}.
\]

Under A1,

\[
\Omega(S,q,a)\geq0.
\]

**Proof.** Add and subtract the term \(\beta V(S)\) inside the maximand in
\(Q\). It is independent of \(d\), so it factors outside the maximum and
leaves exactly the definition of \(\Omega\). It is also independent of \(a\),
which gives the operational ranking. Under A1, choosing \(d=0\) makes the
maximand defining \(\Omega\) equal to zero, so the maximum is nonnegative.
\(\square\)

\(\Omega\) is therefore the incremental value of the development opportunities
that remain available *after* the operational action has been chosen. It is
not the value of operational work, an automatic learning reward, or a claim
that every opportunity should be used.

## 3. Four structural regimes

### I. Opportunity value irrelevant for routing

The exact condition is

\[
\Omega(S,q,a)=\omega(S,q)\qquad\text{for every }a\in\mathcal A(S,q).
\]

Then

\[
a^*(S,q)\in\arg\max_a R(S,q,a).
\]

A sufficient structural condition is

\[
\mathcal D(S,q,a)=\mathcal D(S,q)
\]

for every \(a\), with each action's cost and transition law also independent
of \(a\). Equality of opportunity sets is only sufficient. What is necessary
for \(\Omega\) to disappear from the routing ranking is equality of the
values \(\Omega\), which can occur even when opportunity sets differ.

### II. Local scalar value

Write \(S=(s_1,\ldots,s_K)\). If opportunity \(i\) changes only component
\(s_i\), and its continuation increment satisfies

\[
V(S'_i)-V(S)=V_i(s'_i)-V_i(s_i),
\]

then its scalar value is

\[
g_i=-C_i+\beta\mathbb E[V_i(s'_i)-V_i(s_i)].
\]

Full separability,

\[
V(S)=V_0+\sum_iV_i(s_i),
\]

is sufficient for this representation but stronger than needed: only the
increment generated by this particular opportunity must be local.

### III. Local values with a shared resource

For binary opportunities \(u_i\), local values \(g_i\), resource consumptions
\(r_i\), and budget \(B\), selection is

\[
\max_{u_i\in\{0,1\}}\sum_i g_i u_i
\quad\text{subject to}\quad
\sum_i r_i u_i\leq B.
\]

The opportunity values remain local, but selecting them requires coordination
because of the shared resource. The Lagrangian relaxation ranks by

\[
g_i-\mu r_i.
\]

With integer or binary decisions, a single shadow price \(\mu\) does not in
general recover the exact integer optimum; it solves the relaxation and may
require a combinatorial selection step.

### IV. Joint portfolio valuation

For a set \(D\) of development actions, define

\[
G_S(D)=-C(D)+\beta\{\mathbb E[V(F(S,D))]-V(S)\}.
\]

Individual valuation is exact exactly when

\[
G_S(D)=\sum_{i\in D}G_S(\{i\}).
\]

For two actions,

\[
\Gamma_{12}(S)=G_S(\{1,2\})-G_S(\{1\})-G_S(\{2\}).
\]

With additive costs, \(\Gamma_{12}<0\) denotes substitution or redundancy,
\(\Gamma_{12}=0\) additivity, and \(\Gamma_{12}>0\) complementarity. The
contextual marginal value is

\[
g_i(S\mid D)=G_S(D\cup\{i\})-G_S(D).
\]

### Proposition 2 — Scalar modular sufficiency

Suppose every opportunity has a local transition, its continuation increment
and cost are additive across opportunities, and the only remaining interaction
is through linear resource constraints. Then communicating each opportunity's
scalar value \(g_i\) and resource vector \(r_i\) is sufficient to solve the
development-selection problem.

**Proof.** The hypotheses give

\[
G_S(D)=\sum_{i\in D}g_i.
\]

Every feasible set is determined by the linear resource vectors, so the
central selection problem is completely specified by the collection
\((g_i,r_i)\). \(\square\)

Conversely, if two problems have the same individual values and resources but
require different selections because some \(\Gamma_{ij}\neq0\), an interface
that communicates only \((g_i,r_i)\) cannot be sufficient for both problems.
The missing interaction changes joint set values while leaving the interface
unchanged.

## 4. Fast/deep finite examples

Let \(F\) be a fast/student model with competence \(s\), and let \(D\) be a
deep model with net operational utility \(h\). In the final period,

\[
V(s)=\max\{s,h\}.
\]

An available learning action changes \(s\) to \(f(s)>s\), at cost
\(\kappa\). These examples keep the operational decision \(a\) separate from
the later development choice.

### Region I

If both operational choices enable the same opportunity,

\[
\mathcal D(s,F)=\mathcal D(s,D),
\]

then

\[
\Omega_F=\Omega_D=
[\beta(\max\{f(s),h\}-\max\{s,h\})-\kappa]_+,
\]

and

\[
Q_D-Q_F=h-s.
\]

Learning can have positive value while being irrelevant to routing.

### Region II

If only \(D\) enables the opportunity,

\[
\mathcal D(s,F)=\{0\},\qquad\mathcal D(s,D)=\{0,1\},
\]

then

\[
\Omega_F=0,\qquad
\Omega_D(s)=[\beta(V(f(s))-V(s))-\kappa]_+,
\]

and

\[
Q_D-Q_F=h-s+\Omega_D(s).
\]

For \(h=0.8\), \(s=0.82\), \(f(s)=0.95\), \(\beta=1\), and
\(\kappa=0.05\),

\[
R_D-R_F=-0.02,\qquad\Omega_D=0.08,\qquad Q_D-Q_F=0.06>0.
\]

Thus a short-run operationally inferior action can be optimal because it
creates a valuable development opportunity.

### Region III

For two independent competences,

\[
V_\infty(s_1,s_2)=\max\{s_1,h\}+\max\{s_2,h\},
\]

each opportunity changes only its own competence and has local value \(g_k\).
Adding

\[
z_1+z_2\leq1
\]

creates resource coordination without portfolio coupling.

## 5. Routing-induced substitutability

Consider two independent future task classes. \(F\) has competences
\((s_1,s_2)\). \(D\) has operational utility \(h\), but can serve at most one
class. The future value is

\[
\begin{aligned}
V_{\mathrm{SUB}}(s_1,s_2)
&=\max\{s_1+s_2,h+s_1,h+s_2\}\\
&=s_1+s_2+[h-\min\{s_1,s_2\}]_+.
\end{aligned}
\]

Independent interventions are

\[
A_1:(s_1,s_2)\mapsto(s_1+\Delta_1,s_2),\qquad
A_2:(s_1,s_2)\mapsto(s_1,s_2+\Delta_2),
\]

with \(\Delta_1,\Delta_2\geq0\). Define the finite difference

\[
\Gamma_{\mathrm{SUB}}=
V_{\mathrm{SUB}}(s_1+\Delta_1,s_2+\Delta_2)
-V_{\mathrm{SUB}}(s_1+\Delta_1,s_2)
-V_{\mathrm{SUB}}(s_1,s_2+\Delta_2)
+V_{\mathrm{SUB}}(s_1,s_2).
\]

Additive intervention costs cancel from this difference. Let

\[
u=[h-s_1]_+,\quad v=[h-s_2]_+,\quad
u'=[u-\Delta_1]_+,\quad v'=[v-\Delta_2]_+.
\]

Then

\[
\Gamma_{\mathrm{SUB}}=
\max(u',v')-\max(u',v)-\max(u,v')+\max(u,v).
\]

Without loss of generality let \(s_1\leq s_2\), hence \(u\geq v\). Direct
case reduction gives

\[
\boxed{\Gamma_{\mathrm{SUB}}=-[v-\max\{u',v'\}]_+\leq0.}
\]

Indeed, \(u'\leq u\) and \(v'\leq v\leq u\), so the preceding four-term
expression reduces to
\(\max(u',v')-\max(u',v)\). If \(u'>v\), it is zero; otherwise it is
\(\max(u',v')-v\). These two cases equal the displayed negative-part form.

If \(s_1\leq s_2<h\), strict substitution occurs exactly when

\[
\Delta_1>s_2-s_1\qquad\text{and}\qquad\Delta_2>0,
\]

and then

\[
\Gamma_{\mathrm{SUB}}=
-\min\{\Delta_2,\Delta_1-(s_2-s_1),h-s_2\}.
\]

If \(s_2\geq h\), or if \(s_1+\Delta_1\leq s_2\), the difference is zero.
Equalities, including \(s_1=s_2\), \(s_i=h\), and \(\Delta_i=0\), are
therefore treated as weak boundary cases. For \(s_2<s_1\), exchange indices.

### Proposition 3 — Routing-induced substitutability

With independent competence improvements, two independent future classes, and
one shared future capacity unit of \(D\),

\[
\Gamma_{\mathrm{SUB}}\leq0.
\]

**Proof.** The preceding representation and the WLOG case reduction establish
the inequality. Symmetry covers the opposite competence ordering. \(\square\)

Future scarcity of the backup model \(D\) can therefore produce substitution
between investments even though the learning transitions are independent. It
cannot produce positive complementarity in this model.

## 6. Routing-induced complementarity

Retain exactly the same independent interventions, but change only future
operation. A future task served by \(F\) requires both competences:

\[
R_F(s_1,s_2)=\min\{s_1,s_2\}.
\]

Model \(D\) offers utility \(h\), hence

\[
V_{\mathrm{COMP}}(s_1,s_2)
=\max\{h,\min\{s_1,s_2\}\}
=h+\min\{[s_1-h]_+,[s_2-h]_+\}.
\]

Let

\[
u=[s_1-h]_+,\quad v=[s_2-h]_+,\quad
u'=[s_1+\Delta_1-h]_+,\quad
v'=[s_2+\Delta_2-h]_+.
\]

The finite difference is

\[
\Gamma_{\mathrm{COMP}}=
\min(u',v')-\min(u',v)-\min(u,v')+\min(u,v).
\]

As in the substitution model, additive intervention costs cancel from this
finite difference.

For \(s_1\leq s_2\), \(u\leq v\), so

\[
\boxed{\Gamma_{\mathrm{COMP}}=[\min\{u',v'\}-v]_+\geq0.}
\]

Here \(u'\geq u\) and \(v'\geq v\geq u\), so the four-term expression
reduces to \(\min(u',v')-\min(u',v)\). It is zero when \(u'\leq v\), and
otherwise it equals \(\min(u',v')-v\), which proves the displayed
positive-part form.

If \(s_2<h\), strict complementarity occurs exactly when

\[
s_1+\Delta_1>h\qquad\text{and}\qquad s_2+\Delta_2>h.
\]

If \(s_2\geq h\), it occurs exactly when

\[
s_1+\Delta_1>s_2\qquad\text{and}\qquad\Delta_2>0,
\]

in which case

\[
\Gamma_{\mathrm{COMP}}=
\min\{[\Delta_1-(s_2-s_1)]_+,\Delta_2\}.
\]

All equality cases give weak complementarity. The \(s_2<s_1\) case follows by
index exchange.

For \(h=0.8\), \(S=(0.6,0.6)\), and
\(\Delta_1=\Delta_2=0.3\), each intervention alone has zero incremental value,
whereas jointly

\[
V_{\mathrm{COMP}}(0.9,0.9)-V_{\mathrm{COMP}}(0.6,0.6)=0.1,
\qquad\Gamma_{\mathrm{COMP}}=0.1.
\]

### Proposition 4 — Routing-induced complementarity

With a future task whose value for \(F\) is limited by
\(\min\{s_1,s_2\}\), independent nonnegative improvements satisfy

\[
\Gamma_{\mathrm{COMP}}\geq0.
\]

**Proof.** The WLOG representation is nonnegative; symmetry covers the
opposite ordering. \(\square\)

Complementarity can therefore be induced solely by future operational
architecture, without transfer or interaction in learning dynamics.

## 7. Mixed future workload

Let

\[
V_p(S)=pV_{\mathrm{SUB}}(S)+(1-p)V_{\mathrm{COMP}}(S),
\qquad p\in[0,1].
\]

Linearity of finite differences gives

\[
\Gamma_{12}(p)=p\Gamma_{\mathrm{SUB}}+(1-p)\Gamma_{\mathrm{COMP}}.
\]

When \(\Gamma_{\mathrm{SUB}}<0\) and \(\Gamma_{\mathrm{COMP}}>0\), define

\[
p^*=\frac{\Gamma_{\mathrm{COMP}}}
{\Gamma_{\mathrm{COMP}}+|\Gamma_{\mathrm{SUB}}|}.
\]

Then

\[
p>p^*\Rightarrow\Gamma_{12}(p)<0,\qquad
p=p^*\Rightarrow\Gamma_{12}(p)=0,\qquad
p<p^*\Rightarrow\Gamma_{12}(p)>0.
\]

**Proof.** Substitute
\(\Gamma_{\mathrm{SUB}}=-|\Gamma_{\mathrm{SUB}}|\) and solve the affine
equation \(\Gamma_{12}(p)=0\). \(\square\)

The same competences, improvements, and learning transitions can thus be
substitutes or complements solely because future work composition and
operational constraints differ.

## 8. Interaction induced by selecting between two additive policies

Consider exactly two future operational policies,

\[
V^A(s_1,s_2)=f_A(s_1)+g_A(s_2),\qquad
V^B(s_1,s_2)=f_B(s_1)+g_B(s_2).
\]

Each fixed policy is additive, so its cross difference under the two
independent interventions is zero:

\[
\Gamma_{12}^A=\Gamma_{12}^B=0.
\]

The future HLS selects the better operational policy:

\[
V(S)=\max\{V^A(S),V^B(S)\}.
\]

Define the policy advantage

\[
\delta(S)=V^A(S)-V^B(S),\qquad z=\delta(S),
\]

and the changes in that advantage produced separately by the two independent
improvements:

\[
\begin{aligned}
x&=\delta(S+\Delta_1e_1)-\delta(S),\\
y&=\delta(S+\Delta_2e_2)-\delta(S).
\end{aligned}
\]

Because both policy values, and hence \(\delta\), are additive across the two
components, its four vertex values are

\[
\delta_{00}=z,\quad \delta_{10}=z+x,\quad
\delta_{01}=z+y,\quad \delta_{11}=z+x+y.
\]

Using policy \(B\) as reference gives

\[
V(S)=V^B(S)+[\delta(S)]_+.
\]

The additive reference has zero cross difference. Therefore all interaction
created by future policy selection is exactly

\[
\boxed{
\Gamma(z,x,y)=[z+x+y]_+-[z+x]_+-[z+y]_++[z]_+.
}
\]

### Proposition 5 — Interaction induced by future policy selection

For two additive operational policies and two independent interventions as
defined above,

\[
xy>0\Longrightarrow\Gamma(z,x,y)\geq0,
\qquad
xy<0\Longrightarrow\Gamma(z,x,y)\leq0.
\]

If \(x=0\) or \(y=0\), then \(\Gamma(z,x,y)=0\). Moreover, if one policy is
optimal at all four vertices (weakly, including boundary ties), then
\(\Gamma(z,x,y)=0\).

**Proof.** Let \(\phi(t)=[t]_+\) and
\(H_x(t)=\phi(t+x)-\phi(t)\). Then

\[
\Gamma(z,x,y)=H_x(z+y)-H_x(z).
\]

For \(x>0\), \(H_x\) is nondecreasing in \(t\); for \(x<0\), it is
nonincreasing. Moving its argument by \(y\) therefore gives a nonnegative
difference when \(x\) and \(y\) have the same sign, and a nonpositive
difference when they have opposite signs. If either increment is zero, the
four terms cancel pairwise.

If policy \(A\) is optimal at all four vertices, the four values of
\(\delta\) are nonnegative and \([\delta]_+=\delta\); its cross difference is
zero by additivity. If policy \(B\) is optimal throughout, all four values are
nonpositive and \([\delta]_+=0\), again giving zero. \(\square\)

Thus a change across, or contact with, the policy boundary \(\delta=0\) is
necessary for a nonzero interaction: if the same policy remains optimal
throughout, the interaction vanishes. The converse is false. Merely reaching
or crossing a boundary need not produce a nonzero cross difference, because
the four terms can still cancel. Equality is also possible under either weak
sign result above. In particular, boundary equalities such as
\(z=0\), \(z+x=0\), \(z+y=0\), or \(z+x+y=0\) must be evaluated by the boxed
formula rather than counted automatically as interaction.

Although each operational policy has additive continuation value and the two
learning transitions are independent, the operator
\(V=\max_{\pi\in\{A,B\}}V^\pi\) can therefore generate either substitution or
complementarity between the development actions.

## 9. Exact development-decision regions and value loss

Let the net individual development values be

\[
\begin{aligned}
g_1&=\beta[V(S+\Delta_1e_1)-V(S)]-\kappa_1,\\
g_2&=\beta[V(S+\Delta_2e_2)-V(S)]-\kappa_2,
\end{aligned}
\]

and define the net interaction \(c=\beta\Gamma\). With additive development
costs, the joint net value is exactly

\[
\boxed{g_{12}=g_1+g_2+c.}
\]

Indeed, substituting the cross difference into the right-hand side cancels
the two intermediate continuation values and yields
\(\beta[V(S+\Delta_1e_1+\Delta_2e_2)-V(S)]-(\kappa_1+\kappa_2)\).

The individual baseline selects intervention \(i\) exactly when \(g_i>0\).
When \(g_i=0\), including or excluding it is an explicit indifference. The
portfolio valuation instead selects from

\[
\arg\max\{0,g_1,g_2,g_1+g_2+c\},
\]

corresponding respectively to \(\varnothing,\{1\},\{2\},\{1,2\}\).

### Proposition 6 — Exact strict development-decision changes

Away from ties, the individual and portfolio selections differ exactly in the
following four regions.

| Region | Conditions | Individual selection | Portfolio selection | Exact loss from individual selection |
|---|---|---|---|---|
| A | \(c>0,\ g_1>0,\ -c<g_2<0\) | \(\{1\}\) | \(\{1,2\}\) | \(L=g_2+c>0\) |
| B | \(c>0,\ g_2>0,\ -c<g_1<0\) | \(\{2\}\) | \(\{1,2\}\) | \(L=g_1+c>0\) |
| C | \(c>0,\ g_1<0,\ g_2<0,\ g_1+g_2+c>0\) | \(\varnothing\) | \(\{1,2\}\) | \(L=g_1+g_2+c>0\) |
| D | \(c<0,\ g_1>0,\ g_2>0,\ c<-\min\{g_1,g_2\}\) | \(\{1,2\}\) | singleton with larger \(g_i\) | \(L=-\min\{g_1,g_2\}-c>0\) |

If \(g_1=g_2\) in the strict substitution region D, both singleton sets are
portfolio-optimal; the proposition does not select one of them uniquely.

**Proof.** First take \(c>0\). If both individual values are positive, the
joint set strictly dominates both singletons and agrees with the individual
selection. If \(g_1>0>g_2\), the only possible improvement over \(\{1\}\) is
the joint set, whose value difference is \(g_2+c\); this is positive exactly
in region A. Exchanging indices gives B. If both individual values are
negative, the individual choice is empty and neither singleton can improve
on it. The joint set changes the decision exactly when its value
\(g_1+g_2+c\) is positive, which is C.

Now take \(c<0\). With one positive and one negative individual value, adding
the negative intervention and the negative interaction cannot improve the
positive singleton. With both values negative, the empty set dominates. If
both values are positive, only the joint set and the better singleton can be
optimal. Their value difference, joint minus the better singleton, is

\[
\min\{g_1,g_2\}+c.
\]

It is negative exactly in D. Finally, when \(c=0\), portfolio values are
additive and the selections coincide except for equivalent descriptions of
ties. These sign cases exhaust all possibilities. Subtracting the value of
the individual choice from the portfolio optimum in A--D gives the four
displayed loss formulas. \(\square\)

The strict inequalities exclude the relevant boundaries. At \(g_i=0\), the
individual baseline is indifferent. At \(g_2=-c\) in A (or \(g_1=-c\) in B),
the positive singleton and joint set tie. At
\(g_1+g_2+c=0\) in C, the empty and joint sets tie. At
\(c=-\min\{g_1,g_2\}\) in D, the joint set ties the better singleton. These
are indifference sets, not additional strict decision-change regions.

The model-scoped HLS chain is

```text
heterogeneous competences
    -> alternative future operational policies
    -> V(S) = max_pi V^pi(S)
    -> policy boundaries
    -> Gamma_ij != 0
    -> portfolio-dependent development value
    -> different development decision
    -> difference in future system value.
```

An **intrinsic interaction** is already present within a fixed policy's value.
A **routing-induced interaction** arises here because each fixed
\(V^\pi\) is additive but their pointwise maximum is not. This checkpoint
establishes only the second mechanism, for two additive policies and two
independent interventions.

The exact conclusion is that interaction between development actions need not
be present in the learning dynamics; it can be induced exclusively by future
HLS organization and routing. Ignoring how development changes future
operational options can then produce a suboptimal development decision in the
derived regions. This does not imply that routing and learning must always be
solved jointly, or that joint management generally dominates a sufficiently
coordinated modular architecture.

## 10. Structural interpretation

Two independent axes organize these results.

1. **Operational-development opportunity coupling:** does
   \(\Omega(S,q,a)\) depend on \(a\)? This determines whether development
   opportunity value belongs in current operational routing.
2. **Portfolio coupling:** is \(G_S(D)\) additive? This determines whether
   opportunities can be valued individually or require portfolio context.

Non-additive competence-development value does not require non-additive
learning dynamics. Shared future backup capacity induces substitution, whereas
a joint future competence requirement induces complementarity. In both cases
the interaction enters through \(V(S)\), the structure of future operation and
routing.

## 11. Limits and recorded questions

These exact results do not demonstrate novelty of \(\Omega\), Bellman
decomposition, or finite differences; general superiority of joint or central
management; independent real competence dynamics; a general model of
multi-competence tasks through \(\min\); realism of the workload mixture
\(V_p\); scalability to many models, competences, or teachers; RQ0 in general;
or P4 in general.

They are DERIVED-IN-MODEL analytical results. A sufficiently coordinated
modular architecture can reproduce the relevant choices when it has the
required values, state information, contract, and computation.

Propositions 5 and 6 are additionally limited to two additive future policies
and two independent interventions. They do not establish that every policy
boundary creates interaction, that every interaction changes a development
decision, or that fixed-policy continuation values are additive in real HLS.

Recorded but unresolved questions are:

1. Which classes of \(V(S)\) induce submodularity, supermodularity, or mixed
   development interactions?
2. When do \(\Omega\) or marginal opportunity values admit low-dimensional
   sufficient statistics?
3. How does stochastic future demand change these results while retaining the
   distinction between \(a\) and \(d\)?
4. Which established optimization and control results solve each subclass
   before new machinery is developed?
