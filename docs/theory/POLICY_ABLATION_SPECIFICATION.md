# Frozen prospective policy ablations

## Scope and provenance

This pre-experiment specification implements restrictions of CURRENT as audited
at `7f0df6f` in `CURRENT_POLICY_FORMAL_AUDIT.md`. These are **POLICY ABLATIONS**.
The Strategy-Discrimination Gate and Campaign 2 have not run. No strategy
performance result or trajectory is generated by this freeze.

The environment M, information model I, and policy pi are distinct. M retains
CES, true problems, Gaussian observation noise, and MIS-v2. I retains the finite
hypotheses and Bayesian update. Only pi's prospective propagation switches
change. The switches do not disable real inference or real development.

## Common operator and mode notation

For the existing 64 allocations A, let

```text
mu_m(S,X) = R_z_hat_m(S,X)
g(b,S,X) = sum_m b_m mu_m(S,X)
G(b,S) = max_{U in A} g(b,S,U)
F(S,X)[i,k] = 1-(1-S[i,k]) exp(-lambda X[i,k])
lambda = -log(1-eta)
B(b,S,X,r) = existing numerical finite Gaussian Bayesian posterior
r_mj = mu_m(S,X) + sqrt(2) sigma xi_j
omega_j = w_j/sqrt(pi), j=1,2,3.
```

The likelihood uses pre-development S and current candidate X. B retains the
audited log-weight implementation and its equal-mean tolerance shortcut.
`xi_j,w_j` are the same three-node Hermite rule as CURRENT. The mixture weighs
branches by current b_m and skips zero-probability hypotheses.

| Mode name | Notation | Anticipate information | Anticipate development |
|---|---|---|---|
| NONE | Q00 | false | false |
| INFORMATION_ONLY | Q10 | true | false |
| DEVELOPMENT_ONLY | Q01 | false | true |
| INFORMATION_AND_DEVELOPMENT | Q11 | true | true |

For a two-stage window the exact definitions are

```text
Q00_2(b,S,X) = g(b,S,X) + G(b,S)
Q10_2(b,S,X) = g(b,S,X)
               + sum_m b_m sum_j omega_j G(B(b,S,X,r_mj), S)
Q01_2(b,S,X) = g(b,S,X) + G(b,F(S,X))
Q11_2(b,S,X) = g(b,S,X)
               + sum_m b_m sum_j omega_j G(B(b,S,X,r_mj), F(S,X)).
```

These definitions use numerical quadrature when information is anticipated;
they are not exact continuous-observation integrals. No discount is applied.
For remaining==1, all four give `Q_1=g`. For valid remaining>1 all evaluate two
stages. Thus effective windows remain 2,2,1 within H=3. Terminal value after
the planning window is zero. No subsequent problem is planned.

## Q00 policy equivalence and numerical qualification

Q00's continuation is independent of the current X. Therefore its mathematical
argmax equals `argmax_X g(b,S,X)`, the one-stage immediate policy. Its **value**
is not the H=1 value: the continuation is explicitly retained. No separate
MYOPIC implementation is introduced.

Every mode uses the first action in existing JOINT_ACTIONS order within
`EXACT_TOL=1e-10` of the maximum. Addition of a constant preserves exact-real
gaps and ties. Floating-point rounding of that addition can theoretically
change membership in the tolerance set at its boundary; equivalence is tested
on representative states and exact ties, not asserted bitwise for every
possible floating-point input. No special Q00 tie convention is introduced
to hide that qualification.

## Prospective versus realized transitions

Only terminal evaluation sees the restrictions. In the real system, for a
fixed S,b,X,r, every policy uses the same

```text
b_after = B(b,S,X,r)
S_after = F(S,X).
```

Unknown policies still receive actual noisy observations and update their
beliefs. Every new problem resets belief to the declared prior; real developed
S persists. There is no policy-mode argument in Bayes or MIS-v2. Different
chosen actions can of course produce different real transitions; invariance
is conditional on the same realized inputs.

Historical Campaign 1 NO-DEVELOP disabled development in reality as well as
planning. Q10 only freezes prospective S and must not be executed through that
historical control. Similarly Q00/Q01 freeze prospective belief, not real
inference. No mode-enabled sequence runner is added during this freeze.
The existing sequence runner and its real transition code remain unchanged.

## Implementation and backward compatibility

All definitions live in `src/hls/finite_problem_belief.py`:

- `ProspectivePolicyMode` supplies explicit immutable switch pairs.
- `prospective_action_values` is the single candidate evaluator and returns
  all 64 values in the existing action order.
- `choose_prospective_action` applies the same maximum, tolerance, and first
  qualifying action selection to every mode.
- `finite_choose_dynamic_action_v2` retains its original signature as a
  compatibility wrapper: develop=True selects Q11 and develop=False selects
  Q10. Its historical callers retain their prior behavior.

Information-enabled evaluation retains CURRENT's arithmetic order: current
predictions, immediate g, candidate transition, positive-probability hypothesis
loop, three observation nodes, posterior update, conditional terminal maximum,
weighted accumulation. Information-disabled evaluation computes the same
terminal maximum at frozen b directly. It needs no Bayesian or quadrature call;
integrating this constant would differ only by floating-point summation error.
The common optimizer, terminal helper, action space, immediate objective,
precision, and tie rule are unchanged. This is an algebraic reduction rather
than a different search algorithm.

The known oracle, fixed-S DP, world/observation generation, MIS-v2 implementation,
Bayesian implementation, and historical artifacts are unchanged. No validation
or horizon semantics are silently corrected: as previously audited, selector
invocations must supply positive remaining; historical behavior outside that
valid contract is not part of this intervention.

## Frozen invariants and validation

Campaign 1 constants are inherited unchanged: N=3, K=2, rho=.5, sigma=.10,
eta=.35, H=3, finite repertoire ((.8,.2),(.5,.5),(.2,.8)), uniform reset prior,
and the eight histories at `05b86cb`. No configuration or seed selection changes.

Focused operator tests use fixed unit-test states, not team sequences:

- Six Q11 checks (two states/beliefs × remaining 1,2,3) compare every candidate
  with the pre-refactor computation from audit commit `7f0df6f`: values and
  selected actions are exactly equal, maximum discrepancy zero.
- Q00 retains the continuation and agrees with immediate action selection,
  including an exact symmetry tie fixture.
- All terminal candidate dictionaries coincide without transitions or quadrature.
- Q10 passes unchanged S to every leaf but different simulated posteriors can
  select different terminal actions.
- Q01 passes unchanged b and candidate-dependent developed S; its direct leaf
  value agrees with constant quadrature integration within numerical tolerance.
- Fixed-input real Bayes/MIS-v2 transitions are identical after calls to every
  prospective mode; the sequence runner is unchanged.
- Shared selection preserves existing enumeration and tolerance.

`tests/test_policy_ablation.py` contains these tests and checks manifest hashes.

`results/foundations/policy_ablation/pre_experiment_policy_ablation.json`.

Validation at freeze: 28 focused ablation/protocol/closure tests passed, plus

## Interpretation boundaries and limitations

Use the terms **prospective-information effect**, **prospective-development
effect**, and **coupled prospective effect** for future comparisons until a
separate design supports stronger language. No differences are yet measured
in a Strategy-Discrimination Gate. These ablations do not themselves identify
pure information/development value, additive causal contributions, or
dual-control value.

All modes inherit CURRENT's truncated horizon and finite internal model.
Information-enabled modes inherit three-node observation approximation;
none receives a longer search or richer action repertoire. Q00 policy
equivalence concerns current choice, not equality of value expressions.
Real belief and S trajectories can diverge because policies choose different
actions, but must not diverge because the prospective switches alter M or I.
No claim about comparative performance, adaptive superiority, or strategy
discrimination follows from these unit/regression controls.
