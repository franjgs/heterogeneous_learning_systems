# Heterogeneous Learning Systems

This repository is an evolving research programme on heterogeneous learning
systems. It is a landscape and hypothesis-formation repository: it contains no
validated algorithm, experiment, mathematical result, paper draft, or
established novelty claim.

The programme asks whether the distribution of competence across heterogeneous
agents can be a controllable dynamic property of a system, rather than merely a
fixed input to task routing. Agents may differ in competence, computational
cost, latency, plasticity, specialization, and memory or retention capability.

Current status: **HYPOTHESIS UNDER AUDIT.** Individual ingredients are well
studied; whether their interaction supports a scientifically useful new
formulation or method is not established.

Start with [docs/HANDOVER.md](docs/HANDOVER.md). Literature evidence and its
review status belong in [docs/literature/literature_map.md](docs/literature/literature_map.md),
not in novelty claims.

`adaptive_routing` is an independent prior project, not this repository's
history or implementation base. See [projects/README.md](projects/README.md).
