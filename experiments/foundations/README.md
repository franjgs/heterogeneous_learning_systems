# Foundation reproductions

Reserved for the frozen Beam 1, Beam 2, and Beam 1 + Beam 2 reproductions in
[the experimental foundation specification](../../docs/experimental_foundations/EXPERIMENTAL_SPEC_V0.md).
A per-experiment implementation directory is created only after its source
assumptions, parameter fixture, and pass/fail criterion are ready.

Every implementation records exact lowercase citekeys from
`docs/literature/references.bib`. Experiment kind and epistemic status remain
separate: successful source reproductions use `REPRODUCED`; a literal source
audit that fails uses `FAILED_SOURCE_REPRODUCTION`; an HLS translation uses
`SUPPORTED` only for the explicitly tested property.
