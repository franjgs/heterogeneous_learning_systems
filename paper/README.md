# HLS minimal-theory paper draft

This is a working LaTeX skeleton, not a submission-ready paper. It reports only the internal minimal-model results audited in `docs/theory_competence_evolution_minimal_model.md`.

## Compile

From `paper/`:

```text
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The diagnostic figures are generated by `experiments/microverification/verify_minimal_theory.py` and are read from `../results/microverification/`.

## Structure

`main.tex` imports sections for the motivation, related apparatus, HLS framework, minimal model, model-scoped results, microverification, limits, research programme, and conclusion. `references.bib` contains only verified entries copied from the repository bibliography that are cited by this draft.

## Epistemic status and TODOs

CR0--CR4 are explicitly scoped to the minimal model. Numerical checks are consistency checks, not empirical validation. The draft contains no novelty claim and does not establish P4. Future work must supply a physically grounded competence-transition model, strong matched adversaries, and evidence before any general HLS claim can be made.

TODOs are intentionally substantive rather than cosmetic: establish a defensible mapping from competence state to real operation, define non-separable but physically meaningful transitions, and evaluate whether strong modular controllers can match any joint policy.
